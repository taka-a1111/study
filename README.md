# まいにち計算 ver1.0（算数・自学自習アプリ）

公文式の学習法を調べたうえで、その原則をそのまま動作ロジックに落としたPWAです。
オフライン動作・ホーム画面追加に対応。データはブラウザのローカル保存（端末内）。

## 公文式のノウハウ → 実装の対応

| 公文式の原則 | このアプリでの実装 |
|---|---|
| ちょうどの学習（少しやさしいところから始める） | 初回の診断テスト12問。最後に正解できた位置より 2ステップ手前 を開始位置にする |
| スモールステップ | 6教材（3A・2A・A・B・C・D）を42ステップに分割。1ステップ＝プリント5枚 |
| 自学自習 | 大人が採点・指示しなくても、判定と進級が自動で決まる |
| 反復（くり返し） | 合格しなければ同じプリントをもう1枚。3回続いたらステップの1枚目に戻る |
| 100点にして終わる | 全問解答後にまるつけ。間違いは正解するまで再出題（訂正時間はタイムに含めない） |
| 標準完成時間 | 教材ごとに x秒〜y秒 を設定。x以下＝合格／x〜y＝合格（もう少し速く）／y超＝くり返し。ゲージで残り時間を可視化 |
| 毎日一定量 | 1日のまい数（3・5・10）を設定。ホームのリングで達成度、連続日数を表示 |
| 学年を越えて進む | 学年表示を持たず、教材番号だけで進行 |
| 計算に絞る（文章題・図形なし） | 四則計算のみ。3A〜Dの代数計算の土台に限定 |

## 教材の構成

- 3A たす1〜3
- 2A たす4〜10
- A くり上がりのたし算、ひき算、くり下がり
- B 2〜3けたのひっ算（たし算・ひき算）
- C 九九、2〜3けた×1けた、九九のぎゃく、あまりのあるわり算、2〜3けた÷1けた
- D 2けた×2けた、3けた×2けた、2けた÷2けた、3けた÷2けた

## 使い方

1. ブラウザで開く → 「しんだんテストへ」で開始位置を決める
2. ホーム画面に追加すると全画面のアプリとして動く（iOS: 共有 → ホーム画面に追加）
3. 「ほごしゃ」から 1日のまい数・音・教材の位置・データの書き出し／読みこみ を設定
