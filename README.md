## ver5.8

- 学習画面のスタンプを、星が入った金色の玉に変更した。1枚おえるごとに1つ手に入り、星の数が1つ、2つ…と増えていく。全部そろうと「ぜんぶ そろった！」と表示される。未取得は点線の空枠で、あといくつかが分かる。

## ver5.7

### 訂正しない選択肢
まるつけ画面の「なおす」の下に「なおさずに おわる」を追加した。押すと訂正せずに結果へ進む（点数はそのまま、判定はくり返し）。

公文式は「訂正して100点にしてから終わる」が原則だが、家庭学習では気力が続かない日もあるため、逃げ道を用意しつつ既定の導線は「なおす」のままにしている。

## ver5.6（やる気を支える仕組み）

外からの報酬に寄せず、公文式の「自分のちょうど」を崩さない範囲で4つ入れた。

### 1. じこベスト
ステップごとに全問正解時のタイムを記録し、更新したら結果画面に「★ じこベスト！ まえより ◯びょう はやい」を表示する。他人との比較ではなく過去の自分との比較にしている。

### 2. スタンプカード
学習画面に、その日の目標枚数ぶんの★を表示。1枚おえるごとに埋まり、達成すると「きょうの ぶん かんりょう」に変わる。

### 3. しゅうりょうしょう（修了証）
教材（3A・2A・Aなど）を最後までおえると賞状を発行する。canvasで名前・教材名・日付入りの賞状を描き、画像として保存できる。きろく画面に一覧が残り、あとから見返せる。

### 4. おうちの人からのメッセージ
保護者メニューから、お子さんを選んで定型メッセージ（よくがんばったね！ など5種）を送れる。学習画面の上部にカードで表示され、「ありがとう」を押すと消える。クラウド同期に対応しているので、別の端末から送っても届く。

### 同期への反映
じこベスト（速いほうを採用）、修了証（教材と日付で重複除去）、メッセージ（時刻で重複除去、既読は新しいほう）も端末間で統合する。

### あえて入れていないもの
- 全国ランキングなど他人との比較。公文式は自分に合った位置で進む方式のため逆効果になりやすい
- 連続記録が途切れると全部リセットされる仕組み。プレッシャーが離脱につながるため

## ver5.5（手書きで複数けたをまとめて入力）

- 1文字ずつしか入らなかった手書き入力を、まとめ書きに対応させた。「121」と続けて書くと3けたが一度に入る。
- 処理の流れ
  1. 描いた線を連結成分（つながっているかたまり）に分解する
  2. 4や5のように2画に分かれる数字を、横方向の重なりが34%を超える場合に1文字として結合する
  3. 左から順に並べ、それぞれをMNISTと同じ形（長辺20px・重心中央の28px枠）に整えて認識する
- 横に長い線はマイナス、下のほうの小さな点は小数点として扱う（その問題で必要なときだけ）。
- 認識の待ち時間を0.62秒から0.85秒に延長（複数けたを書き終えるまで待つため）。
- 検証：MNISTの数字を並べた2〜3けたの画像120件で98.3%が完全一致。文字の間隔を-8px（軽く接触）から90pxまで変えても93%を維持。

## ver5.2（家族で共有するクラウド同期）

夫婦それぞれの端末で同じ進度を見られるようにした。

### 使い方
保護者メニューの「クラウド同期（家族で共有）」で、メールとパスワードを入れて「はじめて（アカウントを作る）」。もう1台の端末では同じメールとパスワードで「ログイン」する。以降は自動で同期される。

- プリントを1枚おえるたびに自動保存
- アプリを開くたびに自動で取りこみ
- 手動の「いま すぐ 同期する」「クラウドの 記録を 取りこむ」も用意
- ログアウトしても端末の記録は残る
- 2回目以降のロック解除は指紋認証がそのまま使える（パスワード入力は初回だけ）

### 統合のしかた
同じ子を別々の端末で進めた場合に備え、単純な上書きではなく統合する。
- 履歴：両方を合わせて重複（同じ時刻・同じ教材）を除去し、時系列に並べる
- 進度（教材・枚数）：最後に学習した時刻が新しいほうを採用
- 学習者：片方にしかいない子はそのまま追加
- 例題の既読フラグ：両方の和をとる

### 技術
- Supabase の既存プロジェクト（helm）に kumon_state テーブルを1つ追加。user_id 主キー、payload jsonb、updated_at
- RLS を有効にし、自分の行だけ読み書きできるポリシーを4つ設定
- supabase-js は使わず fetch で REST / Auth を直接叩いている（CDN依存をなくしオフライン動作を保つため）
- アクセストークンが切れたら refresh_token で自動更新

## ver5.1（手書きで答えを入力）

答えを手書きで入力できるようにした。画面は狭くならない。手書きパッドはキーパッドと入れ替わる方式で、追加されるのは切り替えバー（34px）だけ。

- 問題の下に「⌨ キーで こたえる / ✍ 手書きで こたえる」の切り替えバーを追加。
- 手書きモードでは1文字ずつ書く。書き終えて0.6秒待つと認識し、数字が答え欄に入って手書き面が消える。2けた以上は続けて書く。
- 認識した数字は右上に一瞬表示され、答え欄にも反映されるので、違っていれば「けす」で直せる。自信が低いときは「？」を付けて表示する。
- マイナスや小数点は左端のボタン（その問題で必要なときだけ表示）。

### 認識エンジン

MNIST（手書き数字7万枚）で学習した3層のニューラルネットワーク（784→160→64→10）をこのアプリ用に訓練し、int8に量子化して digit_model.json（178KB）として同梱している。

- テスト精度 98.5%（量子化後）、JS実装での実測 98.05%
- 平行移動と濃さのゆらぎを加えて学習し、指で書いた線に対応
- 前処理はMNISTと同じ手順（輪郭で切り出し → 長辺20pxに縮小 → 重心を28px枠の中央に配置）
- サーバーには一切送らない。すべて端末内で処理し、モデルはService Workerがキャッシュするのでオフラインでも動く
- 初回だけ178KBを読みこむ（「よみこみ中…」と表示）

## ver3.9（インストール判定の改善）

「アプリを入れる」で手順表示になってしまう問題への対応。原因は beforeinstallprompt が発火していないことで、主に (a) すでにインストール済み (b) イベントが遅れて届く の2つ。

なお、確認ダイアログなしで自動インストールすることはブラウザの仕様上できない。Androidでは「インストール」→OSダイアログの2タップが最短で、iOSのSafariにはインストールAPI自体が存在しない。

- iOSなど beforeinstallprompt が使えない環境では、同じモーダル内に共有→ホーム画面に追加の手順を表示する。
- インストール完了後は案内もバナーも出さない。

## ver3.4 の修正（1タップインストール）

- beforeinstallprompt を head 内の先行スクリプトで捕まえるようにした。本体スクリプトの実行前にイベントが飛ぶと取り逃してインストールボタンが手順表示になってしまうため。
- manifest に id・display_override・categories・prefer_related_applications を追加し、Chromeのインストール要件を満たす形に整えた。
- インストールがキャンセルされたときだけ手順モーダルを出すようにし、モーダル内にも直接インストールボタンを置いた。

補足：ブラウザの仕様上、確認ダイアログなしで勝手にインストールすることはできない。Android/Chromeではボタン1つ→OSダイアログで「インストール」の2タップが最短。iOSのSafariはインストールAPI自体が提供されていないため、共有→ホーム画面に追加の手順表示になる。

## ver3.3 の追加

- ホーム画面に「アプリとして つかう」バナーを追加。Android/Chromeでは1タップでインストール、iOSやその他のブラウザでは追加手順を表示する。
- 保護者メニューに「アプリとして入れる」「リンクを共有する」を追加。navigator.share対応端末では共有シートが開き、非対応ならリンクをコピーする。
- すでにアプリとして起動している場合（display-mode: standalone）はバナーを出さない。バナーは×で非表示にでき、以降は保護者メニューから入れられる。

## ver3.2 の修正

- 保護者ゲートをアプリ内テンキーに変更。OSのキーボードが出ないので、画面が押し上げられて入力欄が隠れる問題を解消した。
- 自動アップデートを実装。version.json のビルド番号を起動時とアプリ復帰時に確認し、新しければキャッシュを消して自動で読み込み直す。Service Worker もネットワーク優先＋skipWaiting／clients.claim に整理した。

## ver3.1 の修正

- アイコンを作り直し。maskable用（Androidで円形に切り抜かれるもの）は中身を中央40%に収め、端が欠けないようにした。通常用は角丸の全面塗り。
- Androidの戻るジェスチャー・戻るボタンで、アプリを閉じずに前の画面へ戻るようにした。
  - プリント中の戻るは「やめますか」の確認を出す（採点中は無視）
  - まるつけ・けっか・れいだいからの戻るは学習画面へ
  - 保護者メニューは戻る履歴から除外（子どもが戻るで入り込めない）
  - 学習画面での戻るは1回目は何もせず、もう一度でアプリ終了

## ver2.0 からの変更

1. 学習者の登録（複数人）
   名前とアイコンを登録し、進度・記録を人ごとに保存。ホーム右上の「きりかえ」で切替。

2. カリキュラムを147ステップに細分化
   公文式の教材番号（C 11-20 など）にならった刻みに変更。1ステップ＝5枚、全735枚。
   例：C教材は「Bまでの復習／3までの九九／5までの九九／7までの九九／9までの九九／九九ぜんぶ／2けた×1けたの1〜3／3けた×1けた／九九のぎゃくの1・2／あまりのあるわり算の1・2／2けた÷1けたの1・2／3けた÷1けたの1・2／わり算のまとめ／Cのまとめ」の20ステップ。

3. 1問ごとの採点（既定オン）
   答えると ○ が出る。まちがえたら × と正しい答えをその場で表示。

4. まるつけ画面を一覧に変更
   ○が並ぶだけでなく、式・自分の答え・正しい答え（緑）を1問ずつ表示。

5. 保護者メニューにロック
   入るときに2けた×1けたのかけ算に答える必要がある。教材位置の変更にも同じロック。

6. 音声入力
   キーパッドのマイクボタンで答えを声で入力（Chrome等、Web Speech API対応ブラウザ）。
   「じゅうご」「15」「マイナス3」に対応。保護者メニューでオフにできる。

7. 診断テストは日々の学習と分離
   起動時は必ず学習画面。診断テストは登録時と保護者メニューからのみ。

8. デザイン刷新
   「こたえる」ボタンのはみ出しを修正。ボトムナビ4つ、余白と文字サイズを整理。

## 公文式のノウハウ → 実装

| 原則 | 実装 |
|---|---|
| ちょうどの学習 | 学年選択・診断テストとも、解けるところより手前を開始位置にする |
| スモールステップ | 147ステップ、1ステップ5枚 |
| 自学自習 | 各ステップ冒頭に例題（実際に出る問題と答えを自動生成） |
| 標準完成時間 | ステップごとにx秒〜y秒。x以下＝合格／x〜y＝合格／y超＝くり返し |
| 100点にして終わる | 全問終了後に一覧で採点、間違いは正解するまで再出題。訂正時間は計測外 |
| 反復 | 不合格なら同じプリント。3回続いたらステップの1枚目に戻る |
| 毎日一定量 | 1日のまい数、連続日数 |
| 学年を越えて進む | 進行は教材番号のみ |
| 計算に絞る | 文章題・図形は扱わない |
