# まいにち計算 ver2.0

公文式の学習法を調べたうえで、その原則を動作ロジックに落とした算数・数学の自学自習PWA。
スマホ前提のUI。オフライン動作・ホーム画面追加に対応。データは端末内保存。

BUILD_TAG: 2026-09-01b

## ver1.0 からの変更

1. 入口を作り直した
   起動すると「どこから始めるか」を3つから選ぶ画面が出る。学年から選ぶ／診断テスト／教材マップから選ぶ。
2. 教材を 6A〜I まで拡張（ver1.0 は 3A〜D の42ステップ、ver2.0 は 80ステップ）
   J〜O は内容の表示のみ。
3. 新しいステップの前に「れいだい」を表示。学習中も「例」ボタンでいつでも確認できる。
4. 下部に固定ナビ（ホーム／マップ／きろく／せってい）。全画面に戻るボタン。
5. タップ領域を拡大、キーパッドにマイナス・小数点キーを追加。

## 教材の構成（公文式 算数・数学）

| 教材 | 学年目安 | 内容 | 状態 |
|---|---|---|---|
| 6A | 年少ごろ | 10までの数、数の並び | 学習可 |
| 5A | 年少〜年中 | 50までの数、2とび・5とび | 学習可 |
| 4A | 年中ごろ | 120までの数、10とび | 学習可 |
| 3A | 年長〜小1 | たす1〜3 | 学習可 |
| 2A | 年長〜小1 | たす4〜10 | 学習可 |
| A | 小1 | たし算・ひき算の暗算、くり上がり・くり下がり | 学習可 |
| B | 小2 | たし算・ひき算の筆算 | 学習可 |
| C | 小3 | 九九、かけ算、あまりのあるわり算 | 学習可 |
| D | 小4 | 2けたのかけ算・わり算、約分 | 学習可 |
| E | 小5 | 分数の四則計算 | 学習可 |
| F | 小6 | 分数の応用、小数 | 学習可 |
| G | 中1 | 正負の数、文字式、一次方程式 | 学習可 |
| H | 中2 | 連立方程式、一次関数、展開 | 学習可 |
| I | 中3 | 因数分解、平方根、二次方程式 | 学習可 |
| J〜O | 高校 | 数Ⅰ〜数Ⅲ（微分・積分まで） | 内容表示のみ |

学年目安と内容は公文公式サイトおよび公開情報にもとづくおおよその対応。
公文式は学年ではなく教材で進むため、アプリ内でも学年表示は補助的な扱いにしている。

## 公文式のノウハウ → 実装

| 原則 | 実装 |
|---|---|
| ちょうどの学習 | 診断テストは最後に正解した位置の2ステップ手前を開始位置にする。学年選択も学年相当より手前を推奨 |
| スモールステップ | 14教材・80ステップ。1ステップ＝プリント5枚 |
| 自学自習 | 各ステップの冒頭に例題。大人の採点なしで判定と進級が決まる |
| 標準完成時間 | 教材ごとにx秒〜y秒。x以下＝合格／x〜y＝合格／y超＝くり返し。ゲージで可視化 |
| 100点にして終わる | 全問解答後にまるつけ。間違いは正解するまで再出題。訂正時間はタイムに含めない |
| 反復 | 不合格なら同じプリント。3回続いたらステップの1枚目に戻る |
| 毎日一定量 | 1日のまい数（3・5・10）、連続日数を表示 |
| 学年を越えて進む | 進行は教材番号のみで管理 |
| 計算に絞る | 文章題・図形は扱わない |
