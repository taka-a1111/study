# まいにち計算 ver3.9

公文式の学習法をもとにした算数・数学の自学自習PWA。スマホ前提。
BUILD_TAG: 2026-09-01m

## ver3.9（インストール判定の改善）

「アプリを入れる」で手順表示になってしまう問題への対応。原因は beforeinstallprompt が発火していないことで、主に (a) すでにインストール済み (b) イベントが遅れて届く の2つ。

- モーダルを開いたあと最大12秒間、インストール可能になったかを0.5秒おきに確認し、可能になった時点で手順表示を「インストール」ボタンに差し替えるようにした。
- navigator.getInstalledRelatedApps() でインストール済みを判定し、その場合は「すでにアプリが入っています」と表示する。判定のため manifest に related_applications（platform: webapp）を追加した。
- 判定がつくまでは「じゅんびを かくにん しています…」と表示し、手順は下に出したままにした。

なお、確認ダイアログなしで自動インストールすることはブラウザの仕様上できない。Androidでは「インストール」→OSダイアログの2タップが最短で、iOSのSafariにはインストールAPI自体が存在しない。

## ver3.5 の修正（初回に自動で案内）

ver1.0 では beforeinstallprompt を捕まえていなかったため、Chromeが自前のインストール案内を自動表示していた。ver3.3で preventDefault したことでこの自動表示が消え、ボタンを探さないとインストールできなくなっていた。

- 初回にひらいてから約1.4秒後、アプリのアイコン入りの案内モーダルを自動表示するようにした。「インストール」を押すとOSのダイアログが出る。
- 案内は最大3回まで。インストール済み・バナーを閉じた場合は出さない。
- iOSなど beforeinstallprompt が使えない環境では、同じモーダル内に共有→ホーム画面に追加の手順を表示する。
- インストール完了後は案内もバナーも出さない。

## ver3.4 の修正（1タップインストール）

- beforeinstallprompt を head 内の先行スクリプトで捕まえるようにした。本体スクリプトの実行前にイベントが飛ぶと取り逃してインストールボタンが手順表示になってしまうため。
- manifest に id・display_override・categories・prefer_related_applications を追加し、Chromeのインストール要件を満たす形に整えた。
- インストールがキャンセルされたときだけ手順モーダルを出すようにし、モーダル内にも直接インストールボタンを置いた。

補足：ブラウザの仕様上、確認ダイアログなしで勝手にインストールすることはできない。Android/Chromeではボタン1つ→OSダイアログで「インストール」の2タップが最短。iOSのSafariはインストールAPI自体が提供されていないため、共有→ホーム画面に追加の手順表示になる。

## ver3.3 の追加

- ホーム画面に「アプリとして つかう」バナーを追加。Android/Chromeでは1タップでインストール、iOSやその他のブラウザでは追加手順を表示する。
- 保護者メニューに「アプリとして入れる」「リンクを共有する」を追加。navigator.share対応端末では共有シートが開き、非対応ならリンクをコピーする。
- すでにアプリとして起動している場合（display-mode: standalone）はバナーを出さない。バナーは×で非表示にでき、以降は保護者メニューから入れられる。

## ver3.2 の修正

- 保護者ゲートをアプリ内テンキーに変更。OSのキーボードが出ないので、画面が押し上げられて入力欄が隠れる問題を解消した。
- 自動アップデートを実装。version.json のビルド番号を起動時とアプリ復帰時に確認し、新しければキャッシュを消して自動で読み込み直す。Service Worker もネットワーク優先＋skipWaiting／clients.claim に整理した。

## ver3.1 の修正

- アイコンを作り直し。maskable用（Androidで円形に切り抜かれるもの）は中身を中央40%に収め、端が欠けないようにした。通常用は角丸の全面塗り。
- Androidの戻るジェスチャー・戻るボタンで、アプリを閉じずに前の画面へ戻るようにした。
  - プリント中の戻るは「やめますか」の確認を出す（採点中は無視）
  - まるつけ・けっか・れいだいからの戻るは学習画面へ
  - 保護者メニューは戻る履歴から除外（子どもが戻るで入り込めない）
  - 学習画面での戻るは1回目は何もせず、もう一度でアプリ終了

## ver2.0 からの変更

1. 学習者の登録（複数人）
   名前とアイコンを登録し、進度・記録を人ごとに保存。ホーム右上の「きりかえ」で切替。

2. カリキュラムを147ステップに細分化
   公文式の教材番号（C 11-20 など）にならった刻みに変更。1ステップ＝5枚、全735枚。
   例：C教材は「Bまでの復習／3までの九九／5までの九九／7までの九九／9までの九九／九九ぜんぶ／2けた×1けたの1〜3／3けた×1けた／九九のぎゃくの1・2／あまりのあるわり算の1・2／2けた÷1けたの1・2／3けた÷1けたの1・2／わり算のまとめ／Cのまとめ」の20ステップ。

3. 1問ごとの採点（既定オン）
   答えると ○ が出る。まちがえたら × と正しい答えをその場で表示。

4. まるつけ画面を一覧に変更
   ○が並ぶだけでなく、式・自分の答え・正しい答え（緑）を1問ずつ表示。

5. 保護者メニューにロック
   入るときに2けた×1けたのかけ算に答える必要がある。教材位置の変更にも同じロック。

6. 音声入力
   キーパッドのマイクボタンで答えを声で入力（Chrome等、Web Speech API対応ブラウザ）。
   「じゅうご」「15」「マイナス3」に対応。保護者メニューでオフにできる。

7. 診断テストは日々の学習と分離
   起動時は必ず学習画面。診断テストは登録時と保護者メニューからのみ。

8. デザイン刷新
   「こたえる」ボタンのはみ出しを修正。ボトムナビ4つ、余白と文字サイズを整理。

## 公文式のノウハウ → 実装

| 原則 | 実装 |
|---|---|
| ちょうどの学習 | 学年選択・診断テストとも、解けるところより手前を開始位置にする |
| スモールステップ | 147ステップ、1ステップ5枚 |
| 自学自習 | 各ステップ冒頭に例題（実際に出る問題と答えを自動生成） |
| 標準完成時間 | ステップごとにx秒〜y秒。x以下＝合格／x〜y＝合格／y超＝くり返し |
| 100点にして終わる | 全問終了後に一覧で採点、間違いは正解するまで再出題。訂正時間は計測外 |
| 反復 | 不合格なら同じプリント。3回続いたらステップの1枚目に戻る |
| 毎日一定量 | 1日のまい数、連続日数 |
| 学年を越えて進む | 進行は教材番号のみ |
| 計算に絞る | 文章題・図形は扱わない |
